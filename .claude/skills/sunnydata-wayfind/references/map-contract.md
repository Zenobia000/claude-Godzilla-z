# 地圖契約（Map Contract）

按需載入。建立或更新地圖時讀本檔。何時開圖、怎麼走圖、四種 ticket 型別在 [`../SKILL.md`](../SKILL.md)；本檔只管**檔案長什麼樣**。

## 位置

```text
docs/maps/<effort-slug>/
├── map.md                    # 地圖本體 ＋ ticket 表（單一檔案）
└── research/                 # research ticket 的 findings（帶引用），一個問題一檔
```

`<effort-slug>` 用終點的簡短 kebab-case，不用日期或流水號——地圖是靠終點被記住的。

## 為什麼是「一個檔案裡的一張表」而不是一 ticket 一檔

一 ticket 一檔的作法（上游的本地 tracker 就是這樣）在 40 張時變成 40 個檔案，掃一次前緣要開 40 次檔——這正是本專案選擇 Excel 管狀態的原因。但地圖 ticket 的量級是 **10–30 張**，而且它們的內容是**要逐字讀的問題**而非可篩選的欄位，所以一張 markdown 表剛好：一個畫面看完，`git diff` 看得出誰動了什麼。

**升級門檻**：ticket 超過約 30 張，或需要多人真正並行認領時，markdown 表就撐不住了——改用有原子寫入的 tracker（GitHub Issues／Linear）。地圖本體留在 markdown。

## `map.md` 格式

```markdown
# 地圖：<effort 名稱>

## 終點

<走到這張圖的盡頭長什麼樣——這趟要找到的規格、決策或改動。一到兩行；
每個 session 開始前先對齊它，再挑 ticket。>

## Notes

<領域；每個 session 都該載入的 skill；這個 effort 的常設偏好。
若這張圖要把「執行」也納進來，在這裡明文寫出——預設只產出決策。>

## 已決定

<!-- 索引：一張已關閉 ticket 一行。夠判斷相關性即可，細節在 ticket 裡 -->

- **<ticket 標題>**（`WF-003`）— <一行摘要>

## 尚未成形

<!-- 霧：範圍之內、但還講不精準的。前緣推進時會畢業成 ticket -->

- <可疑的問題、之後要回來看的區域。寫得多鬆多細看你現在看得多遠>

## 出界

<!-- 已判定超出終點的工作。永不畢業 -->

- **<摘要>** — <為什麼出界>（`WF-007`，已關閉）

## Tickets

| ID | 問題 | 型別 | Blocked by | 狀態 | 認領者 | 答案 |
|---|---|---|---|---|---|---|
| `WF-001` | <這張 ticket 要解的決策或調查> | grilling | — | 已解決 | sunny | <一行結論，或連到 research 檔> |
| `WF-002` | … | research | WF-001 | 開放 | — | |
```

## 欄位

| 欄位 | 說明 |
|---|---|
| `ID` | `WF-NNN`，建立順序編號。地圖範圍內唯一 |
| `問題` | **一個問題，不是一個任務。** 讀起來要像疑問句 |
| `型別` | `research` / `prototype` / `grilling` / `task`。定義見 SKILL.md |
| `Blocked by` | 逗號分隔的 `WF-*`，或 `—`。只列**真的擋住它**的 |
| `狀態` | `開放` / `認領中` / `已解決` / `已關閉`（出界） |
| `認領者` | session 或人名。**動工前先寫**，空值＝未認領 |
| `答案` | 一行結論。長內容寫成檔案並連結，不要塞進表格 |

**前緣 = `狀態=開放` ∧ `認領者` 為空 ∧ 每個 `Blocked by` 都已解決。** 在 markdown 表上用眼睛掃；掃不動就是該升級了。

## 引用地圖與 ticket 時用名字

每張 ticket 都有標題。**在人要讀的東西裡（敘述、`已決定`）用標題稱呼它，不要用裸 ID。** 一牆的 `WF-42, WF-43, WF-44` 讀不動；名字掃一眼就懂。ID 不會消失——它跟在名字後面的括號裡，但不取代名字。

## 地圖是思考軌跡，不是契約

`WF-*` 不進任何長期追溯關係。地圖記的是**規劃之前**怎麼把霧撥開；決策畢業成 spec 或 plan 之後，它的任務就結束了。

交棒時把畢業的決策連回它的 `WF-*`，這樣「為什麼當初這樣決定」追得回來。地圖**不需要被維護到與程式碼同步**——effort 結束就凍結，之後只讀不改。
