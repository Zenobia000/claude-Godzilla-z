## 1. Change Statement

**As-is**: `VibeCoding_Workflow_Templates/5-views/` 內的兩份前端模板（`frontend-architecture.template.md` 194 行、`frontend-information-architecture.template.md` 156 行）放在 tier 5，但內容大半是規範性目標（技術選型、效能 SLO、A11y 標準、頁面合約），違反 5-views/README.md 與 `rules/context-stability.md` 對 tier 5「Derived from code, never hand-maintained」的硬性定義。

**To-be**: 兩份模板按內容性質拆解到正確 tier（0 principles / 1 decisions / 2 contracts / 3 process / 4 exploration），tier 5 只保留 derived-from-code 的部分（路由表、頁面樹、依賴圖等）。

**Driver**: CLAUDE.md 新增 Context Stability Tiers 規則 + 5-views/README.md 已明文 tier 5 不可手工維護。本次重新分類是規則上線後的 catch-up，避免 AI 後續援引 tier 5 內容當作可信規範來源。
