## 2. 生成 prompt

畫 C4 System Context：中心＝本系統（**一個邊界**，內部子系統最多以淡色分格示意、不展開）。

**前置盤點（防 Partial Disclosure）**——畫圖前先列完整清單再取捨；最常漏的是「不是主流程但會用到」的外部系統：

| 類別 | 清單 |
|---|---|
| Actors | [終端使用者]／[營運人員]／[第三方角色]／[管理員] |
| 外部系統 | [訊息平台]／[第三方 API／供應商]／[雲端平台]／[備份]／[素材或資料來源]（缺類註明「無」） |

## 3. 約束與檢查

- [ ] 方塊只有三種：人（actor）、本系統（圓角矩形、一個）、外部系統（直角矩形、灰）
- [ ] 無內部模組、無開發工具（GitHub／IDE／CI）
- [ ] 每條連線標**互動語意**（領域動詞：[報修／下單／確認…]），協定留給 L2
- [ ] 經統一閘道的外部整合（如 LLM 經 gateway）在線上註明，不畫成多條直連
- [ ] 圖例列出實際用到的配色；metadata banner 已附
