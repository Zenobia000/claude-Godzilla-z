# Ownership Matrix — Human vs AI Division of Labor (v6.0)

> 20 templates. ~7 human-only (decisions / governance), ~13 hybrid (AI drafts + human approves), 0 hand-edited AI-AUTO files (those are now regenerated on demand by `sunnydata-auto-regen` skill).

---

## 3 ownership modes

| Mode | Creates | Edits | Human action |
|---|---|---|---|
| 🟥 **HUMAN-ONLY** | Human | Human | Always — decisions / governance |
| 🟨 **HYBRID** | AI drafts | AI drafts → Human reviews + commits | Approve / amend / reject |
| 🟩 **AI-AUTO** | AI (on-demand) | Skill regenerates | None — never hand-edit; just regenerate |

## What you actually do — the cockpit view

### Daily (when working on a feature)
- Open relevant 🟥 PRIN-0000 to remind yourself of constraints
- Open the 🟥 ARCH-0000 §modules row for the module you're touching
- AI invokes 🟨 CIA-0000 if scope changes
- AI proposes 🟨 hybrid contracts as it implements; you review the diff
- Run 🟩 `sunnydata-flow-audit` weekly (no action unless red)

### Per-project (one-time setup)
- Fill 🟥 PRIN-0000 (mission, non-goals, glossary, unit economics, quality bars)
- Fill 🟥 ARCH-0000 (C4 + modules + stack + infra)
- Adopt 🟥 PROC-0001 (developer handbook — usually copy verbatim, adjust §1 onboarding for your org)
- Decide 🟥 QG-0000 policy (defaults usually fine)

### Per-quarter (stewardship)
- Re-issue 🟨 PLAN-0000 (roadmap)
- Re-validate 🟥 PRIN-0000 §unit-economics
- Review 🟥 ARCH-0000 for drift

## Anti-patterns

| Anti-pattern | Why bad | Correct |
|---|---|---|
| AI silently editing 🟥 HUMAN-ONLY files | Steals your decisions | AI proposes via CR + ADR |
| Hand-editing files that should be regen output | Edits get overwritten | Run regen instead |
| Skipping §8 of a CIA "to save time" | Defeats the gate | CIA without decisions = no implementation |
| Editing accepted ADR | Loses history | Write new ADR with `supersedes` |
