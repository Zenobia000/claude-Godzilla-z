# 承載工作流程的 Output Styles

把 PRD、BDD、TDD、Review、Security 等開發流程做成 output style（舊 01–14 樣式）。

## 為什麼不做

- Output style 一經選用會污染**每一個**後續回答；流程只該在對應階段生效。
- 「格式」與「方法」混在一起，導致同一套流程存在兩份權威（style 版與 skill 版），必然 drift。
- 流程屬於 Action Skills 與能力 Skills；style 只該改呈現。

## 先例

- 14 個流程型 output styles 於 v6.0 移除，理由記錄在 `.claude/OUTPUT_STYLES.md`；現僅存 `15-Vision-output.md`（純呈現）。

## 替代出口

要新的流程 → Action Skill 或能力 Skill；要新的呈現偏好（圖表、結構）→ 純呈現的 output style。
